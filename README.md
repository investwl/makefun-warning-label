One-line entry for make.fun's bounty
[Make the Judge Fall in Love in One Line](https://make.fun/bounty/u-deranalabs-make-the-judge-fall-in-love-in-one-line-8e712c13).

The program authors ~12 candidate one-liners on love & warning labels, scores
each (MAX rating among the lowercase keywords found, case-insensitive, plus
bonuses for a digit and for brevity), then runs a **10-round improvement
loop**: keep the top 5 seeds, spawn light phrasing mutants, rescore, and track
the best line ever seen — with a deterministic RNG seed. Only the champion
line is written to `output/entry.txt`.

## Winning line

> I put a warning label on my heart. It got 0 returns.

## Run

```
python3 main.py -> output/entry.txt
```
