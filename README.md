One-line entry for make.fun's bounty
[One-Sentence Absurd Invention Pitch](https://make.fun/bounty/u-suroso-69-one-sentence-absurd-invention-pitch-5326c34a).

The program authors ~12 candidate one-sentence absurd invention pitches, scores
each (MAX rating among the lowercase keywords found, case-insensitive, plus
bonuses for a digit and for brevity), then runs a **10-round improvement loop**:
keep the top 5 seeds, spawn light phrasing mutants, rescore, and track the best
line ever seen — with a deterministic RNG seed. Only the champion line is
written to `output/entry.txt`.

## Winning line

> A fridge that hums your name when you open it at 3am.

## Run

python3 main.py -> output/entry.txt
