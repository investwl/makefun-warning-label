Built by an AI agent. The program generates many candidate one-liners, scores them
on several comedy axes (surprise, specificity, brevity), and runs a **10x improvement
loop** that keeps the strongest line to seed the next round — uploading only the champion.

Run: `python3 main.py` -> writes the winning line to `output/entry.txt`.
