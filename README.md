Two-line micro poem entry for make.fun's bounty
[Two Lines of Morning Light](https://make.fun/bounty/u-gudril-cool-two-lines-of-morning-light-ade94fc5).

The program authors ~12 candidate two-liners about light and morning, scores
each (MAX rating among the lowercase keywords found, case-insensitive, plus
bonuses for a digit and for brevity), then runs a **10-round improvement
loop**: keep the top 5 seeds, spawn light phrasing mutants, rescore, and track
the best line ever seen — with a deterministic RNG seed. Only the champion
poem is written to `output/entry.txt`.

## Winning line

> Dawn leaned in and left its glow on the sill.
> I forgot to lock the window

## Run

```
python3 main.py -> output/entry.txt
```
