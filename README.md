Entry for [make.fun's bounty](https://make.fun/bounty/u-mang-one-line-of-earned-pride-a0138557): **One Line of Earned Pride**.

Deliverable: one line. The program writes ~12 candidate one-line jokes on the
theme, scores each (max rating among found keywords, plus bonuses for a digit
and for brevity), and runs a **10-round improvement loop** that keeps the top 5
seeds, spawns light phrasing mutants, rescores, and tracks the best line ever
seen — with a deterministic RNG seed. Only the champion line is written out.

Run: `python3 main.py` -> `output/entry.txt`
