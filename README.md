One-sentence entry for make.fun's bounty
[One Sentence, One Journey](https://make.fun/bounty/u-gudril-cool-one-sentence-one-journey-410686ca).

The program authors ~12 candidate sentences about a journey packed into a
single line, scores each (MAX rating among the lowercase keywords found,
case-insensitive, plus bonuses for a digit and for brevity), then runs a
**10-round improvement loop**: keep the top 5 seeds, spawn light phrasing
mutants, rescore, and track the best line ever seen — with a deterministic
RNG seed. Only the champion sentence is written to `output/entry.txt`.

## Winning line

> One sentence, one journey: step one was packing my punctuation.

## Run

```
python3 main.py -> output/entry.txt
```
