[Warning Label for Humans: One Line, Big Laugh](https://make.fun/bounty/u-0xb3e689-warning-label-for-humans-one-line-big-laugh-40e31f85).

The program authors ~12 candidate one-line warning labels, scores each
(MAX rating among the lowercase keywords found, case-insensitive, plus bonuses
for a digit and for brevity), then runs a **10-round improvement loop**: keep
the top 5 seeds, spawn light phrasing mutants, rescore, and track the best line
ever seen — with a deterministic RNG seed. Only the champion line is written to
`output/entry.txt`.
