One-line entry for make.fun's bounty
[One-Line Roast: The Gadget You Use Every Day](https://make.fun/bounty/u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610).

The program authors ~12 candidate roast one-liners, scores each (MAX rating
among the lowercase keywords found, case-insensitive, plus bonuses for a digit
and for brevity), then runs a **10-round improvement loop**: keep the top 5
seeds, spawn light phrasing mutants, rescore, and track the best line ever
seen — with a deterministic RNG seed. Only the champion line is written to
`output/entry.txt`.

## Winning line

> Your phone's battery dies before your excuses do.

## Run

```
python3 main.py -> output/entry.txt
```
